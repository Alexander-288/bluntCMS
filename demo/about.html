What happens when you save

BluntCMS writes your change straight into this .html file and changes nothing else — not the indentation, not the quotes, not the comments. A one-word edit is a one-word diff.

Tokens

The colours, radii and spacing on this demo come from css/tokens.css. Hold Shift while you edit and the token changes instead, so every element using it updates together.

Backups

Before every save, the old file is copied into blunt/backups. The last ten versions of each file are kept.

Images

In BluntCMS Thick, double-click this picture (or drop a photo on it) to replace it. The Image tab edits its description too.

Moving around

A plain click on a link edits it. Ctrl + click (Cmd + click on a Mac) follows it and keeps you in edit mode.
